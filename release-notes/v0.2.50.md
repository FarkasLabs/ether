This release fixes watched episode counts in library, search, and hub listings,
custom collection background artwork and UltraBlur colours, the Release
History search link, and debrid streaming against slow or rate-limiting CDN
edges.

## Playback and library

- **Watched counts in library, search, and hub lists:** shows and seasons that
  have watched episodes now include `viewedLeafCount` (and `viewCount` when all
  regular episodes are watched) in `/library/sections/{id}/all`, `/hubs`, and
  `/hubs/search` responses, so marking a show or season watched stays visible
  when Plex clients refresh from list endpoints (#163).
- **Custom collection artwork on `/art` and UltraBlur:** collections configured
  with a custom artwork URL now use that artwork for `/art` / `/background` and
  derive `UltraBlurColors` from the custom image instead of falling back to the
  first member's TMDB backdrop (#164).
- **Release History title search link:** "Search releases for this title" in
  **Releases → History** now links to `/releases/pinned?key=…&title=…` (where
  the release search lives), and legacy `/releases/search?…` deep links redirect
  to `/releases/pinned` with query parameters preserved (#166).
- **Debrid CDN handshake tolerance, deferred hedging, and backoff:** raised the
  debrid media dial timeout to 10s and TLS handshake timeout to 15s, deferred
  the urgent-read hedge timer until after the primary connection finishes
  DNS/TCP/TLS setup, added per-host exponential backoff (`500ms` to `30s`) on
  connect/TLS/transport failures, and halved the per-host connection cap (down
  to `2`) for 3 minutes after `ECONNRESET`/`WSAECONNRESET` or HTTP `429` (#162).
